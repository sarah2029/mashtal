# مَشتل — النسخة المستقلة

تطبيق ويب **مجاني بالكامل** يعمل لأي شخص بدون حساب:
- **التعرّف على النبتة:** Pl@ntNet يقترح النوع، ثم Gemini يتحقق منه بالصورة ويكتب دليل العناية.
- **التشخيص والمحادثة:** Gemini (الخطة المجانية من Google).
- **الموسوعة وحديقتي:** تعمل بدون إنترنت.

المفاتيح السرية تبقى في الخادم (مجلد `api`) ولا تظهر للزوار.

## محتوى المجلد
| الملف | وظيفته |
|---|---|
| `index.html` | واجهة التطبيق |
| `api/identify.js` | التعرّف (Pl@ntNet + Gemini) |
| `api/diagnose.js` | تشخيص المشكلة وخطة الإنعاش |
| `api/ask.js` | «اسأل مَشتل» |
| `api/_lib.js` | الإعدادات المشتركة والتعليمات للذكاء الاصطناعي |

## خطوات النشر (مرة واحدة، حوالي 20 دقيقة)

### 1. خذي المفتاحين (مجانيين، بدون بطاقة)
- **Gemini:** من aistudio.google.com ← سجّلي بحساب Google ← **Get API key** ← **Create API key**. انسخيه واحفظيه.
- **Pl@ntNet:** من my.plantnet.org ← سجّلي ← Settings ← انسخي API key. يسمح بـ 500 تعرّف يومياً.

### 2. ارفعي المجلد على GitHub
github.com ← New repository باسم `mashtal` ← Add file ← Upload files ← اسحبي كل محتويات المجلد ← Commit.
(لا ترفعي أي ملف فيه مفاتيحك الحقيقية.)

### 3. انشريه على Vercel (مجاني)
vercel.com ← Sign up with GitHub ← Add New Project ← اختاري `mashtal` ← قبل Deploy افتحي **Environment Variables** وأضيفي:
- `GEMINI_API_KEY` = مفتاح Gemini
- `PLANTNET_API_KEY` = مفتاح Pl@ntNet

ثم Deploy. بعد دقيقة يصير عندك رابط مثل `mashtal.vercel.app` يفتح على أي جوال.

### 4. (اختياري، يُنصح به) اقفلي الخادم على موقعك
أضيفي متغيراً ثالثاً `ALLOWED_ORIGIN` = رابط موقعك بالضبط (مثل `https://mashtal.vercel.app`) ثم Redeploy.

## على الجوال
افتحي الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»، فيظهر كأيقونة مثل التطبيقات.

## ملاحظات
- **التكلفة:** صفر. الخطتان المجانيتان لهما حد يومي؛ إذا انتهى حد Gemini يكمل التطبيق التعرّف بـ Pl@ntNet ويعرض دليل العناية من الموسوعة إن وُجدت النبتة فيها.
- **الخصوصية:** Google تستخدم بيانات الخطة المجانية لتحسين خدماتها، فلا يُرسل في المحادثة أي معلومات شخصية.
- **حماية:** كل زائر محدود بـ 20 تحليل كل 10 دقائق.
- **الاستخدام التجاري:** خطة Pl@ntNet المجانية مخصصة للاستخدام غير الربحي. إذا صار التطبيق تجارياً تحتاجين خطة مدفوعة.
- إذا غيّرت Google أسماء نماذجها، يختار التطبيق أحدث نموذج Flash متاح تلقائياً.
