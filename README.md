# مَشتل — النسخة المستقلة

تطبيق ويب يعمل لأي شخص بدون حساب Claude:
- **التعرّف على النبتة:** Pl@ntNet يقترح النوع، ثم Claude يتحقق منه بالصورة ويكتب دليل العناية.
- **التشخيص والمحادثة:** Claude.
- **الموسوعة وحديقتي:** تعمل بدون إنترنت ولا تكلّف شيئاً.

المفاتيح السرية تبقى في الخادم (مجلد `api`) ولا تظهر للزوار.

## محتوى المجلد
| الملف | وظيفته |
|---|---|
| `index.html` | واجهة التطبيق |
| `api/identify.js` | التعرّف (Pl@ntNet + Claude) |
| `api/diagnose.js` | تشخيص المشكلة وخطة الإنعاش |
| `api/ask.js` | «اسأل مَشتل» |
| `api/_lib.js` | الإعدادات المشتركة والتعليمات للذكاء الاصطناعي |

## خطوات النشر (مرة واحدة، حوالي 20 دقيقة)

### 1. خذي المفتاحين
- **Claude:** من console.anthropic.com ← سجّلي ← Billing وأضيفي رصيداً صغيراً ← API Keys ← Create Key.
  - **مهم:** من Limits حدّدي سقفاً شهرياً للصرف (مثلاً 10 دولار) حتى لا تُفاجئي بفاتورة.
- **Pl@ntNet:** من my.plantnet.org ← سجّلي ← Settings ← انسخي API key. المجاني يسمح بـ 500 تعرّف يومياً.

### 2. ارفعي المجلد على GitHub
github.com ← New repository باسم `mashtal` ← Add file ← Upload files ← اسحبي كل محتويات المجلد ← Commit.
(لا ترفعي أي ملف فيه مفاتيحك الحقيقية.)

### 3. انشريه على Vercel (مجاني)
vercel.com ← Sign up with GitHub ← Add New Project ← اختاري `mashtal` ← قبل Deploy افتحي **Environment Variables** وأضيفي:
- `ANTHROPIC_API_KEY` = مفتاح Claude
- `PLANTNET_API_KEY` = مفتاح Pl@ntNet

ثم Deploy. بعد دقيقة يصير عندك رابط مثل `mashtal.vercel.app` يفتح على أي جوال.

### 4. (اختياري، يُنصح به) اقفلي الخادم على موقعك
أضيفي متغيراً ثالثاً `ALLOWED_ORIGIN` = رابط موقعك بالضبط (مثل `https://mashtal.vercel.app`) ثم Redeploy.

## على الجوال
افتحي الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»، فيظهر كأيقونة مثل التطبيقات.

## ملاحظات
- **التكلفة:** كل تعرّف أو تشخيص يُخصم من رصيد Claude بمبلغ صغير (تقريباً سنتات قليلة، حسب أسعار النموذج الحالية في console.anthropic.com). المحادثة أرخص. Pl@ntNet مجاني ضمن الحد اليومي. السقف الشهري يحميك.
- **حماية:** كل زائر محدود بـ 20 تحليل كل 10 دقائق.
- **الاستخدام التجاري:** خطة Pl@ntNet المجانية مخصصة للاستخدام غير الربحي. إذا صار التطبيق تجارياً (مثلاً مدفوع على App Store) تحتاجين خطة مدفوعة منهم.
- إذا توقف Pl@ntNet أو انتهى الحد اليومي، يكمل التطبيق التعرّف بـ Claude وحده تلقائياً.
